# jbodea.github.io

Personal website of Jonathan Bodea, live at https://jbodea.github.io. It is a static site served by GitHub Pages, with no build step.

- `index.html`: homepage
- `papers/unipo/`, `papers/turning-the-tables/`: paper pages
- `stylesheet.css`, `scripts/animations.js`: styling and scroll animations
- `images/`: photos, paper images, logos and favicons
- `data/turningTables.pdf`: Turning the Tables paper PDF
- `sitemap.xml`, `robots.txt`, `CNAME`: SEO and custom domain files

Built from [Jon Barron's website template](https://github.com/jonbarron/website).
